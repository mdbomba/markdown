# LDAP

LDAP endpoint configuration for admin authentication and SSO integration. Supports LDAP, LDAPS, and STARTTLS protocols.

## Commands (11)

| Command | Description |
|---------|-------------|
| [`access/addldapendpoint`](access-addldapendpoint.md) | Creates LDAP endpoint |
| [`access/deleteldapendpoint`](access-deleteldapendpoint.md) | Removes LDAP endpoint |
| [`access/modifyldapendpoint`](access-modifyldapendpoint.md) | Updates LDAP endpoint |
| [`access/showldapendpoint`](access-showldapendpoint.md) | Shows ldapendpoint |
| [`access/showldaplist`](access-showldaplist.md) | Shows ldaplist |
| [`access/aclcontrol`](access-aclcontrol.md) | Removes global packet filter ACL |
| [`access/aclcontrol.isenabled`](access-aclcontrol.isenabled.md) | Checks if the packet routing filter is enabled |
| [`access/aclcontrol.isdrop`](access-aclcontrol.isdrop.md) | Checks if connections are dropped or rejected when on the blocked list |
| [`access/aclcontrol.isifblock`](access-aclcontrol.isifblock.md) | Checks if the restrict traffic to interfaces option is enabled |
| [`access/aclcontrol.iswuiblock`](access-aclcontrol.iswuiblock.md) | Checks if the include WUI in IP access lists option is enabled |
| [`access/aclcontrol.wuiaddr`](access-aclcontrol.wuiaddr.md) | Checks the IP address of the last client that changed the packet filter |
